# Mayur Mahant - Personal Portfolio

Welcome to my personal portfolio website showcasing my professional experience, CV, and projects.

## Features

- 📄 **CV Section** - Download and view my complete curriculum vitae
- 💼 **Tasks & Projects** - Showcase of my work and projects
- 🎨 **Responsive Design** - Looks great on desktop, tablet, and mobile
- ⚡ **Fast & Lightweight** - Pure HTML/CSS for optimal performance

## Website Sections

1. **About** - Personal introduction and bio
2. **CV** - Professional experience, education, and skills
3. **Tasks & Projects** - Portfolio of work and projects
4. **Contact** - Ways to get in touch

## Getting Started

1. Update the content in `index.html`:
   - Replace placeholder text with your actual information
   - Add your projects and tasks
   - Update contact links (email, GitHub, LinkedIn, etc.)

2. Customize the styling in `styles.css`:
   - Change colors and fonts
   - Adjust layout as needed

3. (Optional) Add a `cv.pdf` file to the repository for download

4. Your site will be live at: `https://mmahant17.github.io`

## How to Update

Simply edit the HTML and CSS files and push to the main branch. GitHub Pages will automatically rebuild your site.

### To add more projects:
Edit the `<section id="tasks">` in `index.html` and add more `.task-card` divs.

### To update your CV:
Edit the `.cv-section` divs with your actual experience, education, and skills.

## Customization Tips

- **Colors**: The main color scheme uses gradients from `#667eea` to `#764ba2`. Edit these hex values in `styles.css` to match your preference.
- **Fonts**: Change the font-family in `styles.css` to use different Google Fonts or system fonts.
- **Layout**: The site is fully responsive and uses CSS Grid for layouts.
